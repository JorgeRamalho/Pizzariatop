# Benchmark — delivery de pizzarias (síntese)

## Padrões observados no mercado BR

| Padrão                    | Pizzaria Top hoje | Recomendação                          |
| ------------------------- | ----------------- | ------------------------------------- |
| CTA principal WhatsApp    | Sim               | Manter (baixo atrito)                 |
| Carrinho no site          | Sim               | Evoluir com tamanho/borda             |
| Cupom em faixa superior   | Sim (`TOPTERCA`)  | Manter; medir uso                     |
| Prova social (nota iFood) | Sim (4,9)         | Linkar perfil real                    |
| Tempo de entrega no hero  | Sim (45 min)      | Manter acima da dobra                 |
| Cardápio filtrável        | Sim               | Labels amigáveis                      |
| SEO local (bairro/cidade) | Fraco             | Incluir bairro no title/H1 secundário |
| Preview social (OG)       | Ausente           | P0                                    |

## Diferenciais a reforçar

1. Massa 48h / forno a lenha — conteúdo visual próprio
2. Frete grátis &gt; R$ 80 — já no strip e no carrinho
3. Combo Família — bom banner; amarrar ao WhatsApp com mensagem pré-preenchida

## O que evitar

- Contatos placeholder em produção
- Dependência total de stock photos
- Múltiplos CTAs iguais (“Montar pedido” → `#cardapio` sem ação nova)
