# Pesquisas e referências

## Contexto de produto

Delivery de pizza local: decisão rápida, confiança visual e caminho curto até o pedido (WhatsApp).

## Inspirações de UX (delivery / food)

- Hierarquia clara: promoção → cardápio → pedido
- CTA recorrente para WhatsApp / telefone
- Fotos de produto com carga preguiçosa (`loading="lazy"`)
- Mobile-first: menu colapsável, botões grandes, carrinho acessível

## Referências técnicas do stack atual

| Tema    | Escolha                     | Motivo                          |
| ------- | --------------------------- | ------------------------------- |
| Markup  | HTML semântico              | SEO e acessibilidade            |
| Estilo  | CSS próprio (design system) | Controle total da marca         |
| Lógica  | TypeScript → JS             | Tipagem e manutenção            |
| Hosting | GitHub Pages                | Deploy simples de site estático |
| Pedido  | WhatsApp (`wa.me`)          | Zero fricção para o cliente     |
