# Plano do projeto

## Objetivo

Site de delivery da **Pizzaria Top** com identidade italiana contemporânea, cardápio interativo, carrinho e pedido via WhatsApp.

## Escopo atual (MVP)

- Landing page completa (promoção, hero, cardápio, promoções, como pedir, sobre, contato)
- Filtros de cardápio (clássicas, especiais, doces)
- Carrinho lateral com total
- Checkout via WhatsApp
- Layout responsivo e menu mobile
- Identidade visual (logo, cores, tipografia)

## Fora de escopo (por enquanto)

- Backend / banco de dados
- Pagamento online
- Painel administrativo
- Conta de usuário / fidelidade digital

## Roadmap sugerido

| Fase | Entrega                                             | Status       |
| ---- | --------------------------------------------------- | ------------ |
| 1    | Site estático + TypeScript + marca                  | Em andamento |
| 2    | Conteúdo real (cardápio, telefone, endereço, redes) | Pendente     |
| 3    | SEO local e performance (imagens, meta tags)        | Pendente     |
| 4    | Integrações (iFood, formulário, analytics)          | Futuro       |

## Critérios de sucesso

- Visitante entende a proposta em poucos segundos
- Consegue montar pedido e enviar no WhatsApp sem atrito
- Marca reconhecível e consistente em todas as seções
- Estrutura de pastas clara para manutenção e evolução
